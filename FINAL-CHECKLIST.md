# Финальная сверка конкурсного задания

22 ноября 2026 года

## Выполнено

- **Конкурсный режим.** Собственные SECRET, SAST и SCA. Ground Truth используется после анализа для сравнения. Экспериментальные внешние сканеры запускаются отдельной командой. На открытом наборе 15 совпадений из 15, по пять на категорию. Ни один из шести контрольных примеров не отмечен.
- **Входные данные.** Dashboard анализирует встроенный Repair Desk или публичный учебный GitHub-репозиторий из серверного списка. Для каждого разрешённого источника закреплён коммит. Проверены загрузка архива официального источника и 15 находок на импортированном снимке. Локальный каталог передаётся CLI. Репозиторий выбирается для ручного прогона, расписание использует встроенный проект.
- **Визуальный конструктор.** Ноды, направленные связи, конфигурация, сохранение, открытие, шаблоны и архивирование графа. Валидация проверяет циклы, порты, параметры и достижимость. Исполнитель следует графу.
- **Условия и расписание.** Ветки True и False, объединение находок, пропущенные ноды, ручной и плановый запуск, локальная история. Тесты покрывают повторное открытие SQLite и защиту от дублирования слота расписания.
- **Экспорт.** JSON и Markdown формируются из одних находок. Проверены формат, относительные пути и маскирование значений. В изменённой копии учебного проекта Kotlin-файлы переименованы и перемещены, их строки сдвинуты и добавлены отступы. Найдено 15 записей с тем же распределением по категориям.
- **Уведомления.** Webhook по активной ветке отправляет итог анализа после завершения вычислительных нод. Для доставки нужны HTTP 2xx и разрешённый адрес. Локальный приёмник подтверждает `runId`. Внешний HTTPS проверяется отдельно с разрешённым сервером получателя.
- **Демонстрация.** Full Security Audit содержит три сканера, Condition, AI Analysis, Report Generator и HTTP Webhook. Инструкция репетиции и текст выступления находятся в [DEMO-GUIDE.md](DEMO-GUIDE.md).
- **Браузер.** Playwright и Edge 158.0.4370.33 проверили выбор шаблона, перетаскивание, соединение True и False, редактирование, масштаб, сохранение и повторное открытие после перезагрузки. Проверены реальные события исполнения, история, 15 находок, экспорт обоих форматов и HTTP 200 от локального webhook. Для AI-контракта использован локальный HTTP-стенд.

## Частично выполнено

- **AI на реальной модели.** Интеграция, строгий JSON, сверка ID, путей, строк и advisory покрыты HTTP-тестами. В текущей среде отсутствует настроенный облачный API и Ollama недоступен на loopback. Перед защитой требуется подключить модель и проверить один структурированный ответ по инструкции.
- **Покрытие скрытого набора.** Проверен открытый набор и его изменённая локальная копия. Результат скрытого набора пока неизвестен.

## Невыполнено на текущей машине

- Прогон с реальной LLM и проверка её качества объяснений. При отсутствии модели используется подтверждённый режим продолжения с отчётом сканеров и статусом ошибки AI.
